# LicaTech

Página de servicios de LicaTech: desarrollo web, hosting y mantenimiento.

Sitio estático en un solo archivo (`index.html`) con HTML, CSS y JavaScript, sin dependencias.

## Configuración

Edita el objeto `CONFIG` al final de `index.html`:

- `marca`: nombre de la marca
- `whatsapp`: número con indicativo de país, solo dígitos (ej. `573001234567`)
- `telefonoVisible`: número como se mostrará en la página
- `correo`: correo de contacto
- `dominio`: dominio del sitio

## Publicar con GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)`.
